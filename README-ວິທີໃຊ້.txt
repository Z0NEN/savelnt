====================================================================
 ລະບົບແຈ້ງເຫດຂໍຄວາມຊ່ວຍເຫຼືອຜູ້ປະສົບໄພນ້ຳທ່ວມ
 ໄຟລ໌ໃນໂຟນເດີ:
   - index.html            = ຕົວເວັບແອັບ (ໄຟລ໌ດຽວ)
   - supabase_schema.sql   = SQL ສ້າງຕາຕະລາງ requests
   - start-server.bat      = ເປີດ web server ໃນເຄື່ອງ (ທົດລອງ)
====================================================================

--------------------------------------------------------------------
 ຂັ້ນຕອນ 1) ຕັ້ງຄ່າ Supabase (ເຮັດເທື່ອດຽວ)
--------------------------------------------------------------------
1. ເຂົ້າ https://supabase.com  ->  ສ້າງ Project ໃໝ່
2. ໄປ SQL Editor -> ວາງໂຄ້ດທັງໝົດຈາກ supabase_schema.sql -> ກົດ Run
   (ຖ້າເຄີຍ Run ຮອບກ່ອນແລ້ວ ໃຫ້ Run ຄືນ ເພື່ອເພີ່ມ policy ອັບເດດ)
3. ໄປ Project Settings -> API  ->  ຄັດລອກ 2 ຄ່າ:
      - Project URL
      - anon public key
4. ເປີດ index.html ດ້ວຍ Notepad/VS Code ຫາ 2 ແຖວນີ້ (ຢູ່ເທິງສຸດຂອງ <script>):
      const SUPABASE_URL = "PUT_YOUR_SUPABASE_URL_HERE";
      const SUPABASE_ANON_KEY = "PUT_YOUR_SUPABASE_ANON_KEY_HERE";
   ແລ້ວແທນທີ່ດ້ວຍຄ່າຂອງທ່ານ -> Save

--------------------------------------------------------------------
 ຂັ້ນຕອນ 2) ທົດລອງ
--------------------------------------------------------------------
 ວິທີ A - ທົດລອງໄວໃນເຄື່ອງ (map + ແຕະເລືອກຈຸດ ໃຊ້ໄດ້, GPS ໃນມືຖືໃຊ້ບໍ່ໄດ້):
   - ດັບເບິນຄລິກ start-server.bat
   - ເປີດ http://localhost:8000 ໃນເຄື່ອງ
   - ໃນມືຖື (WiFi ດຽວກັນ): ເປີດ http://[IP-ທີ່ບອກໃນໜ້າຈໍ]:8000

 ວິທີ B - ທົດລອງໃນມືຖືໃຫ້ GPS ໃຊ້ໄດ້ (ແນະນຳ) = Deploy ຂຶ້ນ Vercel:
   1. ໄປ https://vercel.com  (login ດ້ວຍ GitHub/Email)
   2. ກົດ Add New -> Project -> Deploy
      ວິທີງ່າຍສຸດ: ໄປ https://vercel.com/new  ແລ້ວລາກໂຟນເດີ savelnt
      (ທີ່ມີ index.html) ໄປວາງ  ->  ລໍຖ້າ Deploy
   3. ຈະໄດ້ລິ້ງ https://xxxx.vercel.app  ->  ເປີດໃນມືຖືໄດ້ເລີຍ GPS ໃຊ້ໄດ້

--------------------------------------------------------------------
 ⚠️ ເປັນຫຍັງ GPS ຈຶ່ງໃຊ້ບໍ່ໄດ້ບາງເທື່ອ?
--------------------------------------------------------------------
 - ບຣາວເຊີອະນຸຍາດ GPS ສະເພາະເວັບທີ່ເປັນ HTTPS ຫຼື localhost ເທົ່ານັ້ນ
   => ເປີດແບບ file:// (ດັບເບິນຄລິກໄຟລ໌) ຫຼື http:// ທຳມະດາ = GPS ຖືກ block
   => ໃຊ້ Vercel (HTTPS) GPS ຈະໃຊ້ໄດ້
 - ໃນຄອມພິວເຕີ desktop GPS ໃຊ້ WiFi/IP ຈຶ່ງຄາດເຄື່ອນຫຼາຍ (ບໍ່ແມ່ນຢຳ)
   ໃນມືຖືຈະໃຊ້ GPS ຈິງ ຈຶ່ງແມ່ນຢຳກວ່າ
 - ຖ້າ GPS ບໍ່ໄດ້ຢູ່ດີ ໃຫ້ "ແຕະເລືອກຈຸດເທິງແຜນທີ່" ໄດ້ໂດຍກົງ

--------------------------------------------------------------------
 ຄຸນສົມບັດ
--------------------------------------------------------------------
 - ໜ້າເວັບພາສາລາວ, ແຜນທີ່ Responsive ເໝາະມືຖື
 - ດຶງ GPS ຫຼື ແຕະເລືອກຈຸດເທິງແຜນທີ່
 - ໝຸດແບ່ງສີຕາມຄວາມເລ່ງດ່ວນ (ແດງ/ສົ້ມ/ຂຽວ/ເທົາ)
 - ກົດໝຸດ = ເຫັນລາຍລະອຽດ + ເວລາແຈ້ງເຫດ
 - ປຸ່ມ "ໝາຍວ່າຊ່ວຍເຫຼືອແລ້ວ" ໃນ popup -> ໝຸດປ່ຽນເປັນສີເທົາ ✓
